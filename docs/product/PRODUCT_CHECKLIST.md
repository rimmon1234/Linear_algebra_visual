# PRODUCT_CHECKLIST.md

Use this as a quick product-level review before major milestones.

## Learning

- [ ] Definitions are mathematically correct.
- [ ] Intuition precedes heavy formalism where appropriate.
- [ ] Examples are consistent with formulas.
- [ ] Students can practice the concept.

## Visualization

- [ ] Geometry is mathematically truthful.
- [ ] Student can manipulate meaningful parameters.
- [ ] Numerical values correspond to visuals.
- [ ] Visualizer does not become the only source of explanation.

## Engineering

- [ ] Math and rendering remain separated.
- [ ] Topics remain data-driven.
- [ ] AI output is validated.
- [ ] Tests cover new behavior.
- [ ] Performance is acceptable.

## Product

- [ ] Student can understand what changed.
- [ ] Controls are discoverable.
- [ ] Errors are understandable.
- [ ] Mobile experience remains usable.
